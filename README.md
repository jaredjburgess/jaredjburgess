## Current work

### Aster

**Mission: build a private AI health researcher grounded in your own
longitudinal data.**

Aster is a local-first health intelligence app for macOS. It unifies
wearable and nutrition data, lab results (including blood tests),
genetic data and self-tracked health information in one coherent
longitudinal view, while keeping provenance and source freshness visible.

Its goal is to turn fragmented health information into a trustworthy
foundation for cited, reviewable AI analysis and research. I am building it
end to end: the React/TypeScript interface, local SQLite data model, native
macOS application shell, provider integrations and a consent-gated,
multi-stage agentic AI pipeline that separates private health data from
web research.

Aster is currently in private alpha and its source code remains private.
